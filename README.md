# Mathcad Prime для Claude

> ⚠️ **Сырой продукт.** Скилл собран из опыта работы с несколькими реальными документами в Mathcad Prime 10 и проверен на них, но широко не тестировался. Тестировалось с моделью **Claude Opus 5.5**: на других моделях Claude может вести себя иначе. В других версиях Маткада и на необычных документах возможны ошибки. Работайте с копиями файлов и проверяйте результат. Сообщения об ошибках и предложения приветствуются в Issues.

Скилл для [Claude Code](https://claude.com/claude-code), который учит Claude работать с файлами **PTC Mathcad Prime** (`.mcdx`) так, как это делал бы аккуратный человек: открыть ваш документ, поменять нужные числа, формулы или текст, пересчитать его в самом Маткаде, сохранить и выгрузить в PDF и проверить, что всё посчиталось и ничего не съехало.

## Зачем это нужно

Маткад не умеет «давать себя редактировать» снаружи. Его программный интерфейс позволяет только открыть файл, пересчитать и сохранить, но не позволяет добавить формулу или поменять текст. Без подсказок Claude либо ломает файл, либо пишет, что не справится.

Этот скилл закрывает пробел. В нём собран отработанный порядок действий и набор готовых скриптов:

- **правка документа напрямую**: числа, единицы, формулы, матрицы, функции, уравнения в блоках Given/Find, текст, картинки;
- **добавление и удаление формул внутри текста** так, что Маткад потом открывает документ без ошибок;
- **пересчёт и экспорт в PDF через установленный Маткад**;
- **проверка**: сверка результатов с независимым расчётом, поиск ошибок вычислений, просмотр каждой страницы PDF;
- **защита от типичных ловушек**: съезжающая вёрстка, «устаревшие» результаты в файле, закрытие вашего открытого Маткада, перезапись чужих правок.

Типичные сценарии:

- «Сделай копию этого расчёта с другими исходными данными».
- «Пересчитай документ и сохрани в PDF».
- «Проверь, правильно ли посчитан мой файл».
- «Замени картинку и подпиши результаты».

Скилл не привязан к предметной области. Он умеет обращаться с Маткадом, а что именно считается в документе, неважно.

## Что нужно

- Windows и установленный **Mathcad Prime** (проверено на версии 10).
- **Python 3.8+** (для проверки PDF дополнительно пакет `pymupdf`, установщик ставит его сам).
- Claude Code.

## Установка

**Одной командой (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/ZUBENIN-INDUSTRIES/skill_in_using_claude_with_mathcad_prime/main/install.ps1 | iex
```

Скилл установится в `%USERPROFILE%\.claude\skills\mathcad-prime` и будет доступен во всех проектах. Перезапустите Claude Code или начните новую сессию.

**Через git (Git Bash):**

```bash
git clone --depth 1 https://github.com/ZUBENIN-INDUSTRIES/skill_in_using_claude_with_mathcad_prime /tmp/mcs && mkdir -p ~/.claude/skills && cp -r /tmp/mcs/mathcad-prime ~/.claude/skills/
```

**Только для одного проекта:** скопируйте папку `mathcad-prime` в `.claude/skills/` внутри проекта.

## Как пользоваться

Ничего вызывать не нужно: Claude сам подключает скилл, когда в запросе есть Маткад или файл `.mcdx`. Примеры:

> Открой C:\расчёты\балка.mcdx, поменяй длину на 4,5 м и нагрузку на 12 кН, пересчитай и сохрани рядом как балка_v2.mcdx и PDF.

> Проверь файл отчёт.mcdx: нет ли ошибок в расчёте и всё ли влезает на страницы.

Перед тем как трогать файл, Claude попросит закрыть его в Маткаде, если он у вас открыт. Работает он с копией, а итог сохраняет под новым именем.

## Что внутри

```
mathcad-prime/
├── SKILL.md              порядок работы и правила
├── reference/            справочники: формат файла, запись формул, текст, вёрстка, COM-API, проверка
└── scripts/
    ├── mcdx.py           библиотека правки .mcdx (только стандартный Python)
    ├── recalc.ps1        пересчёт в Маткаде и сохранение в .mcdx / .pdf
    ├── check.py          результаты, ошибки, страницы PDF
    └── measure.py        реальные размеры блоков для выравнивания вёрстки
```

## Ограничения

- Новые документы скилл делает на основе существующего файла, хотя бы пустого, сохранённого в Маткаде. С абсолютного нуля он документ не создаёт.
- Значения читаются из сохранённого Маткадом файла, а не «вживую» через программу.
- Формат `.mcdx` закрытый. Всё, что знает скилл, получено разбором реальных файлов Mathcad Prime 10. В других версиях возможны отличия, а проверки в скилле нужны как раз чтобы их заметить.
